# Exercício TypeScript

Este repositório contém um exercício prático desenvolvido em TypeScript como parte do curso da EBAC.

## Descrição

O código implementa duas funções principais:

1. **multiplicar(a: number, b: number): number**  
   Recebe dois números como parâmetros e retorna o resultado da multiplicação.
